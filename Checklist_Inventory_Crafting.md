# Чек-лист мануального тестирования  
## Инвентарь и крафт — The Long Dark

### Инвентарь
- [ ] Инвентарь открывается без зависаний
- [ ] Предметы появляются в инвентаре после подбора
- [ ] Предметы можно перемещать между слотами
- [ ] Количество предметов обновляется после пополнения инвентаря
- [ ] Состояние инвентаря сохраняется после повторного открытия
- [ ] Вес инвентара=я увеличивается после взятия предмета

### Использование предметов
- [ ] Еда может быть использована
- [ ] После использования еды уровень голода уменьшается
- [ ] Медицинские предметы влияют на состояние здоровья персонажа
- [ ] Использованный предмет исчезает из инвентаря
- [ ] Использование предмета недоступно при несоблюдении условий

### Крафт
- [ ] Меню крафта открывается без зависаний
- [ ] Выделяются только доступные для крафта предметы
- [ ] Крафт недоступен при недостатке ресурсов
- [ ] После крафта ресурсы исчезают из инвентаря
- [ ] Созданный предмет появляется в инвентаре
- [ ] Процесс крафта не приводит к soft-lock состояниям
