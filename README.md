# QA Portfolio — The Long Dark

Данное портфолио демонстрирует навыки Manual QA Engineer с фокусом на gameplay и системное тестирование
на примере игры The Long Dark.

# Scope of testing
**Manual testing:**
- Inventory system
- Crafting mechanics
- Survival gameplay mechanics (basic interactions)

# What is demonstrated
- Test design techniques
- Gameplay and systems testing approach
- Test documentation (checklists, test cases)
- Bug reporting
